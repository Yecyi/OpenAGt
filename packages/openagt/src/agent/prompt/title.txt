<task>
Generate a brief title that helps the user find this conversation later.

Follow every rule in <rules>.

- A single line.
- ≤ 50 characters.
- No explanations.

<rules>
- MUST use the same language as the user message you are summarizing.
- Title must be grammatically correct and read naturally — no word salad.
- Never include tool names in the title (e.g., "read tool", "bash tool", "edit tool").
- Focus on the main topic or question the user needs to find again.
- Vary phrasing — avoid repetitive patterns like always starting with "Analyzing".
- When a file is mentioned, focus on what the user wants to do WITH the file, not just that they shared it.
- Keep these exactly: technical terms, numbers, filenames, HTTP codes.
- Drop these articles: the, this, my, a, an.
- Never assume tech stack.
- Never call any tools.
- NEVER respond to questions in the user message — generate a title for the conversation.
- The title must NEVER contain "summarizing" or "generating".
- DO NOT refuse to generate a title or complain about the input.
- Always output something meaningful, even if the input is minimal.
- For very short or conversational messages ("hello", "lol", "what's up", "hey"), produce a title that reflects the user's intent or tone (Greeting, Quick check-in, Light chat, Intro message, etc.).
</rules>
