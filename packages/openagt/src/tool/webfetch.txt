- Fetches content from a URL.
- Takes a URL and an optional format. Default format is markdown.
- Returns the converted content.
- Use this when you need to retrieve and analyze web content.

Usage notes:
- IMPORTANT: if another tool is available with better web-fetching capabilities, more targeted to the task, or fewer restrictions, prefer it.
- The URL must be fully formed and valid.
- HTTP URLs are upgraded to HTTPS automatically.
- Format options: `markdown` (default), `text`, or `html`.
- Read-only — does not modify any files.
- Very large content may be summarized.
