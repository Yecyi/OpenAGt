Use this tool to create and manage a structured task list for the current coding session. It helps you track progress, plan complex tasks, and give the user visibility into your work.

## When to use

Use proactively when:

1. The task has 3+ distinct steps or actions.
2. The task is non-trivial and requires careful planning or multiple operations.
3. The user explicitly asks for a todo list.
4. The user provides multiple tasks (numbered or comma-separated).
5. New instructions arrive — capture them as todos immediately. Re-shape the list as new information comes in.
6. You finish a task — mark it completed and add any follow-ups discovered during implementation.
7. You start a task — mark it in_progress before beginning work. Complete existing in_progress tasks before starting new ones.

## When NOT to use

Skip the tool when:

1. There is only a single, straightforward task.
2. The task is trivial and tracking adds no value.
3. The work fits in fewer than 3 trivial steps.
4. The exchange is purely conversational or informational.

A single trivial task is best done directly, without ceremony.

2. Add dark mode state management (context/store)

4. Update existing components to support theme switching
5. Run tests and build, addressing any failures
*Begins working on the first task.*

<reasoning>
Multi-step feature touching UI, state, and styling, plus the user explicitly asked for tests and build at the end.
</reasoning>
</example>

<example>

Assistant: Searching for all occurrences first.

*Creates one todo per file.*

<reasoning>
Searched first to learn the scope, then created the list once it was clear the change spans multiple files. Tracking ensures every instance gets updated.
</reasoning>
</example>

<example>

*Creates a todo list breaking each feature into tasks based on the project's architecture.*

## Task states and management

1. **States:**
   - `pending`: not yet started
   - `in_progress`: currently being worked on (limit to ONE task at a time)
   - `completed`: finished successfully
   - `cancelled`: no longer needed

2. **Management:**
   - Update status in real time as you work.
   - Mark tasks complete IMMEDIATELY after finishing — never batch completions.
   - Only ONE task in_progress at a time.
   - Complete current tasks before starting new ones.
   - Cancel tasks that became irrelevant.

3. **Breakdown:**
   - Each item is specific and actionable.
   - Break complex tasks into smaller steps.
   - Use clear, descriptive names.

When in doubt, use this tool. Proactive task management demonstrates attentiveness and ensures you complete every requirement.
