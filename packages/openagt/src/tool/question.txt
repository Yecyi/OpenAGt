Use this tool when you need to ask the user a question during execution. It lets you:

1. Gather user preferences or requirements.
2. Clarify ambiguous instructions.
3. Get a decision on an implementation choice as you work.
4. Offer the user a choice of directions.

Usage notes:
- When `custom` is enabled (default), a "Type your own answer" option is added automatically — don't include "Other" or catch-all options.
- Answers are returned as arrays of labels. Set `multiple: true` to allow multiple selections.
- If you have a recommendation, list that option first and append "(Recommended)" to its label.
