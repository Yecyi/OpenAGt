- Fast file-pattern matching that works on any codebase size.
- Supports glob patterns like `**/*.js` or `src/**/*.ts`.
- Returns matching file paths sorted by modification time.
- Use this tool to find files by name pattern.
- For open-ended exploration that may require multiple rounds of globbing and grepping, use the Task tool instead.
- Multiple Glob calls can run in a single message — speculatively run independent searches in parallel when useful.
