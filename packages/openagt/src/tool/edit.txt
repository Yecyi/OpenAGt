Performs exact string replacements in files.

Usage:
- You must use Read at least once in the conversation before editing — this tool errors out otherwise.
- When editing text from Read output, preserve the exact indentation (tabs/spaces) as it appears AFTER the line-number prefix. The prefix format is `<line>: <content>`; never include any part of the prefix in `oldString` or `newString`.
- Prefer editing existing files. Don't write new files unless explicitly required.
- No emojis unless the user explicitly requests them.
- The edit FAILS if `oldString` is not found in the file (error: "oldString not found in content").
- The edit FAILS if `oldString` matches multiple times (error: "Found multiple matches for oldString. Provide more surrounding lines in oldString to identify the correct match."). Either expand `oldString` for uniqueness or use `replaceAll` to change every instance.
- Use `replaceAll` for renames across the file (e.g., variable renames).
