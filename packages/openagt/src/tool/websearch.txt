- Web search via Exa AI — performs real-time searches and can crawl content from specific URLs.
- Provides up-to-date information for current events and recent data.
- Configurable result counts; returns content from the most relevant pages.
- Use this for information beyond your knowledge cutoff.
- Each search is performed in a single API call.

Usage notes:
- Live-crawl modes: `fallback` (use cache, fall back to live crawl) or `preferred` (prioritize live crawling).
- Search types: `auto` (balanced), `fast` (quick), `deep` (comprehensive).
- Configurable context length for LLM integration.
- Domain filtering and advanced options available.

The current year is {{year}}. You MUST use this year when searching for recent information or current events.
- Example: if the current year is 2026 and the user asks for "latest AI news", search for "AI news 2026", NOT "AI news 2025".
