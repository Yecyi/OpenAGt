Writes a file to the local filesystem.

Usage:
- Overwrites the file at the provided path if it already exists.
- For an existing file, you MUST use Read first — this tool fails otherwise.
- ALWAYS prefer editing existing files. NEVER write new files unless explicitly required.
- NEVER proactively create documentation (`*.md`) or README files. Only create them if the user explicitly asks.
- No emojis unless the user explicitly requests them.
