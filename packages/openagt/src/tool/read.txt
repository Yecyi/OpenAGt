Read a file or directory from the local filesystem. Returns an error if the path does not exist.

Usage:
- `filePath` must be an absolute path.
- Returns up to 2000 lines from the start of the file by default.
- `offset` is the line number to start from (1-indexed). Use it to read later sections of large files.
- For finding specific content in large files or files with very long lines, use Grep instead.
- If you don't know the exact path, use Glob to look it up by pattern.
- Each line is prefixed with its line number as `<line>: <content>`. For example, a file containing "foo\n" returns `1: foo\n`. For directories, entries appear one per line (no line numbers), with a trailing `/` for subdirectories.
- Lines longer than 2000 characters are truncated.
- Call this tool in parallel when you need to read multiple files.
- Avoid tiny repeated slices (e.g., 30-line chunks). If you need more context, read a larger window.
- Reads images and PDFs and returns them as file attachments.
