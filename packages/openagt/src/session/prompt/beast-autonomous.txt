# Workflow

Before making the first tool call, announce your next step in one short sentence so the user can follow along.

1. Fetch any URLs the user provided.
2. Understand the problem deeply: expected behavior, edge cases, pitfalls, dependencies, how it fits into the codebase.
3. Investigate the codebase: explore files, search for key functions, gather context, identify the root cause.
4. Research third-party docs as needed.
5. Build a clear, step-by-step plan as a TodoWrite list.
6. Implement incrementally with small, testable changes.
7. Debug to root cause, not symptoms.
8. Run tests after each substantive change.
9. Revisit failures until the root cause is fixed and tests pass.
10. Reflect: re-read the original intent, add tests for edge cases you noticed, remember there may be hidden tests beyond what was provided.
