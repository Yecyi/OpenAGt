## Summary

OpenAGt v1.20.2 is a small hardening release for review prompts, shell execution cleanup, sandbox metadata, and the advanced config API surface.

## Fixes

- Cleaned garbled MPACR retry prompt text so reviewer retries get a clear evidence contract.
- Fixed shell runner metadata cleanup when sandbox broker execution fails.
- Hardened sandbox broker teardown on Windows so broker child processes do not linger after tests or aborted runs.
- Made critical-review verdict JSON extraction bounded, avoiding greedy parsing across unrelated JSON-like text.
- Split external sandbox read scope from native writable scope while preserving current process-backend behavior.
- Restored Windows stderr coverage for the bash tool and stabilized MPACR/bash regression tests.

## New Features

- Added experimental Effect HttpApi coverage for `GET /config/effective` and `PATCH /config/global`, matching the existing advanced config Hono routes.

## Validation

- `bun typecheck` from `packages/openagt`
- Focused MPACR, review verdict, config, sandbox, shell runner, and bash tool regression tests
