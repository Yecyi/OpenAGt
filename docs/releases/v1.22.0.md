# OpenAGt v1.22.0 Release Notes

OpenAGt v1.22.0 is a GA-readiness release for the v1.21 runtime expansion. It does not introduce a new product direction; it closes partially finished release, safety, and observability work so the MPACR / 3LMA / expert-runtime line can ship with truthful operational claims.

## Highlights

- **Unified shell safety path.** The main `ShellSecurity` analysis path now consumes the unified dangerous-command detector, so PowerShell, cmd, and POSIX findings flow into the same `shell_safety` risk and final decision envelope used by the Bash tool.
- **Instance-partitioned bus persistence.** Critical and opt-in behavior audit events persist under an instance-specific event log instead of the previous global `events.jsonl`, preventing different workspaces from replaying each other's event history.
- **GA CI smoke matrix.** PR checks now include a cross-platform GA smoke job for Ubuntu, macOS, and Windows that builds the SDK, typechecks `packages/openagt`, runs focused runtime tests, builds a platform release asset, and smokes the packaged binary.
- **Offline release generation support.** `packages/openagt/script/generate.ts` can use `MODELS_DEV_API_JSON`, the checked-in model snapshot, or a checked-in fallback if `models.dev` is unavailable.
- **Default enterprise integration tests no longer false-fail.** S3/R2-backed enterprise storage/share tests are skipped unless `OPENCODE_STORAGE_ADAPTER` is configured.
- **Stable docs realigned.** Stable install and architecture docs now describe the v1.22 support matrix instead of stale v1.16/v1.20 text.

## Verification

```bash
bun run verify:v1.22

cd packages/sdk/js && bun run script/build.ts && bun typecheck
git diff --check
```

## Known Limitations

- Windows native sandbox default-on remains opt-in until elevated ACL apply and WFP evidence are current. The process backend remains advisory and does not provide OS-native filesystem or network isolation.
- Scheduled memory consolidation remains manually invoked. Long-running automatic scheduler integration is deferred.
- MPACR `final_revise` without a concrete target continues to use the legacy reviser path.
- Calibration-informed expert weighting is exposed as recommendation data only; it does not automatically change dispatch weights.
- Vector embeddings, TUI panels for calibration/prompt/expert stats, runtime-core package-boundary work, and Effect/Drizzle/AI SDK major upgrades are v1.23+ roadmap items.
- Windows assets are signed only when Azure Trusted Signing secrets are configured in the release workflow. Without those secrets, Windows assets may show `Unknown publisher`.
